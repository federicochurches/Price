
### ⚠️ Importante: cómo subir archivos al proyecto Claude

El proyecto Claude **no reemplaza** archivos con el mismo nombre — los duplica. Para evitar acumulación:

1. **Antes de subir el ZIP delta** → borrar los archivos viejos del proyecto que van a ser reemplazados
2. **O una vez por mes** → borrar todo y subir el ZIP completo limpio (39 archivos)

Si el proyecto llega a >50 archivos es señal de que hay duplicados acumulados.
